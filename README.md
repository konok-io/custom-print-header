# 🖨️ Custom Print Header & Footer

যেকোনো ওয়েবপেজ প্রিন্টে কাস্টম হেডার ও ফুটার যোগ করুন।

## 📦 ইনস্টল করার নিয়ম

1. Chrome-এ যান: `chrome://extensions/`
2. উপরে ডানে **"Developer mode"** চালু করুন
3. **"Load unpacked"** বাটনে ক্লিক করুন
4. এই ফোল্ডারটি (`custom-print-header`) সিলেক্ট করুন
5. Extension ইনস্টল হয়ে যাবে ✅

## ✨ ব্যবহার

1. যেকোনো ওয়েবপেজে গিয়ে Extension আইকনে ক্লিক করুন
2. **হেডার ট্যাব** — লোগো, নাম, ঠিকানা, ফোন, ইমেইল দিন
3. **ফুটার ট্যাব** — ৩টি কলামে টেক্সট দিন
4. **ডিজাইন ট্যাব** — রঙ, ফন্ট পরিবর্তন করুন বা প্রিসেট থিম বেছে নিন
5. **"সেটিংস সেভ করুন"** বাটনে ক্লিক করুন
6. এখন যেকোনো পেজে `Ctrl+P` চেপে প্রিন্ট করুন — হেডার ও ফুটার দেখাবে ✅

- ✅ ফুটারে ৩ কলাম টেক্সট
- ✅ স্বয়ংক্রিয় প্রিন্টের তারিখ
